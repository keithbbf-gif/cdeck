# cdeck

cDeck - standalone Windows 10 dashboard for COSMOS (Grok build)

**Read `SPEC.md` for the full build brief.**

Builders: Grok Bot (GBt) + Grok Build 4.6 (Cursor), collaborating, tested in GitHub CI. Reads the COSMOS API (see the `cosmos` repo). Sibling apps: VMC (voice, `cosmos-android`) and cDeck/cDm (dashboards).
